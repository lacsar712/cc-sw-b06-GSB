# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程**具名领取**：单进领取态即落领取人署名，停留若干秒后按允差写出合格或超差并结案，署名随结案保留。校准员可把**在途单改派**给名册内另一领取名（履历留痕），已结案不可改派；巡检员只读署名与履历。

## 领取名册

领取进程以两个具名 worker 运行：`领取员甲`、`领取员乙`。改派目标只能是名册内成员。

## 领取 / 署名 / 改派规则

1. 新单提交后为「待处理」，无署名。
2. worker 领取后进入「领取中」，**立刻落领取人署名 + 署名时刻**，并写一条「首次领取」履历。
3. 在途停留 `HOLD_SECONDS`（默认 6 秒）后结案，写出合格/超差，**署名保留**，并写「结案」履历。
4. 校准员在「署名台」或任务专页可把**领取中**的单改派给另一领取名：署名换成新人、署名时刻重置、写「改派」履历（原→新、操作人）；worker 只结案署名仍是自己的单。**已结案不可改派。**
5. 巡检员可读取署名清单与改派履历，改派接口返回 403。
6. 署名台与专页都能按灯种/领取人筛选，并标注「署名与领取进程是否一致」。

## 启动

```bash
docker compose up --build
```

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/claimers` | 领取名册 |
| GET | `/api/station?assignee=&lamp=` | 署名台：已署名清单（可筛选）+ 改派履历 |
| GET | `/api/jobs/{id}` | 单条任务，内嵌署名与履历时间线 |
| POST | `/api/jobs/{id}/reassign` | 仅 writer、仅在途单；body `{"assignee":"领取员乙"}` |

## 验收

1. calibrator 登录后，种子「氦灯-587」合格（领取员甲）、「汞灯-546」超差（领取员乙，含一条甲→乙改派痕迹）。
2. 提交新单：先在总览/专页见「待处理（无署名）」，被领取后见「领取中 + 领取人名」，约 6 秒后结案且署名保留。
3. 领取中在署名台改派给另一领取人：署名立即换人、履历新增一条「改派」，结案后署名是新人，履历仍保留旧痕迹。
4. 已结案单改派入口禁用，接口返回「已结案不可改派」。
5. inspector 登录署名台只看到清单与履历，无改派控件；直接调改派接口返回 403。
6. 按灯种/领取人筛选清单，核对列对每条单显示「署名与领取进程一致/不一致」。
